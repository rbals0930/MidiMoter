# MidiMotor — 4채널 스텝모터 오케스트라 (v6.0)

Arduino Uno + CNC Shield V3 + A4988 × 4 + NEMA17 × 4 하드웨어를 웹 브라우저(`Web Serial API`)로 제어해, MIDI 파일 및 유튜브·오디오 음원을 4단 계층(`베이스 → 미들 → 멜로디 → 하이`) 4성부 화음으로 연주하는 프로젝트입니다.

---

## 주요 기능

- **웹 컨트롤러 (`web/`)**: 별도 빌드 없이 Chrome/Edge에서 `web/index.html` 바로 실행
  - **6단계 작업 흐름 UI & 도움말**: 모터 상태 → 곡 불러오기 → 재생 & 소리 다듬기 → 피아노 롤 편집 → 가상 건반 → 통신 로그 구성, 상단 `[기능 안내]` 모달 및 `로그 접기/펼치기` 지원
  - **시리얼 제어**: `Web Serial API` (115200 bps) 실시간 4채널 연주, 스텝 분주(1/1 ~ 1/16) 보정, 4축 자체 테스트 및 채널별 음소거
  - **4채널 피아노 롤 직접 편집 & 4트랙 `.mid` 저장**: `구간 이동` / `악보 편집` 모드 전환, 음표 추가·이동·길이 조절·삭제, Undo/Redo, 박자 맞춤(`자유 / 4분 / 8분 / 16분음표`), 전체화면·양방향 가로 스크롤바, 새 빈 악보, 표준 4트랙 `.mid` 내보내기(`midiExporter.js`)
  - **표준 MIDI 4축 자동 분배 (`midiParser.js` v6.0)**: 외부 5~16트랙 `.mid` 파일에서도 단선율 솔로 비분열 + `X(하이) > Y(멜로디) > Z(미들) > A(베이스)` 비침범 4단 계층 자동 배분 (`X-Axis / Y-Axis / Z-Axis / A-Axis` 트랙명 자동 고정 매핑 지원)
  - **3그룹 실시간 소리 다듬기**:
    - *재생 · 음높이*: `재생 속도(0.5x~2.0x)`, `음높이(반음 ±12)`, `옥타브 이동(±2)`
    - *모터 음질 · 타건감*: 채널별 독립 `음표 끊김(스타카토 0~80ms)`, `고음 제한(탈조 방지 C6/E6/G6/무제한)`, `빈 모터 화음 채우기`
    - *MIDI 분배 · 잡음 정리*: `4모터 분배 규칙(계층 자동 / 단순 음높이)`, `짧은 잡음 무시(ms)`, `약한 잡음 무시(세기)`, 트랙별 모터 직접 지정
  - **브라우저 미리듣기 & 내보내기**: 타건감과 동음 재타건이 보강된 `Web Audio API` 4채널 미리듣기, 실시간 가상 건반, Arduino Uno 단독 실행 `.ino` 저장(`exporter.js`)
- **아두이노 펌웨어 (`MidiMoter_4Axis/MidiMoter_4Axis.ino`)**
  - Timer1 20kHz CTC 인터럽트 + 32비트 DDS + 포트 레지스터 직접 제어
  - 무음 2초 유지 시 드라이버 자동 비활성화(발열 보호)
- **로컬 AI 변환 서버 (`backend/`, v6.0, 선택 사항)**
  - `FastAPI` + `yt-dlp` + `librosa` + `Demucs(htdemucs)` 드럼 제거 + `basic-pitch` ONNX
  - **드럼 블리드·배음 고스트 제거 + 동적 16분음표 칼박 퀀타이즈 + 보이스 리딩 비분열 4단 계층 엔진**: 3가지 변환 모드(`빠른 변환 clean` / `고품질 변환 stems(권장)` / `디테일 보존 detail`)로 유튜브 URL 또는 MP3/WAV 파일을 4트랙 표준 `.mid`로 자동 변환

## 하드웨어 핀맵 (CNC Shield V3 기준)

| 채널 (축) | 역할 (4단 계층) | STEP | DIR | 비고 |
| :---: | :--- | :---: | :---: | :--- |
| **CH 0 (X)** | 하이 (최고음 리드) | D2 | D5 | 독립 제어 |
| **CH 1 (Y)** | 멜로디 (중고음) | D3 | D6 | 독립 제어 |
| **CH 2 (Z)** | 미들 (중저음 화음) | D4 | D7 | 독립 제어 |
| **CH 3 (A)** | 베이스 (최저음) | D12 | D13 | CNC Shield `D12/D13` 독립 점퍼 설정 |
| **ENABLE** | 공통 활성 | D8 | - | `LOW` = 활성 / `HIGH` = 비활성 |

## 실행 방법

### 1. 아두이노 펌웨어 업로드 (1회)
1. Arduino IDE에서 `MidiMoter_4Axis/MidiMoter_4Axis.ino`를 열어 Arduino Uno에 업로드합니다. (추가 라이브러리 불필요)

### 2. 웹 컨트롤러 실행
1. Chrome 또는 Edge에서 `web/index.html`을 엽니다. (사용법이 헷갈릴 때는 우측 상단 `[기능 안내]` 버튼을 눌러 전체 가이드를 확인할 수 있습니다.)
2. 상단 `[시리얼 연결]`로 포트를 연결하고, 외부 `.mid` 악보 파일·내장 데모 곡·가상 건반을 재생하거나 ④ 피아노 롤의 `[악보 편집]`으로 직접 음표를 다듬어 보세요. *(가장 깔끔한 연주를 원하시면 `.mid` 파일 직접 사용을 추천합니다.)*

### 3. 로컬 AI 변환 서버 실행 (악보 파일이 없을 때 유튜브 / MP3 변환)
```bash
cd backend
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
start_server.bat
```
서버 실행(`http://127.0.0.1:8765`) 후 웹 페이지에서 유튜브 URL 또는 오디오 파일을 바로 4트랙 MIDI로 변환할 수 있습니다. (드럼이 강한 곡은 **`고품질 변환 (stems)`** 모드를 권장합니다.)
